# partner-resources

Hands-on resources for Port partners — learn Port, see real use cases, and pick up implementation best practices through self-guided workshops.

## Workshops

- **[intro-workshop/](intro-workshop/)** — Port 101. Build a data model, self-service actions, and a dashboard from scratch.
- **[customization-workshop/](customization-workshop/)** — Deploy a custom Ocean integration via Helm and build a custom UI plugin, entirely in Kubernetes.
- **[advanced-workshop/](advanced-workshop/)** — AI agents and agentic workflows. Build two AI agents, then wire them into a running workflow that triages and remediates incidents automatically.

Each workshop is self-contained with its own README. `intro-workshop` and `advanced-workshop` also include a `check-completion.sh` script to verify your progress against the Port API.
